# Templates

Templates para criar novas notas rapidamente. Copie o template, renomeie o arquivo com a convenção correta e preencha os campos marcados com `[colchetes]`.

## Índice

- [[templates/decisao-arquitetural]] — Para registrar uma decisão nova de arquitetura ou design
- [[templates/bug-resolvido]] — Para documentar um bug já corrigido com causa raiz
- [[templates/novo-estilo-prompt]] — Checklist completo para criar um novo estilo de prompt
- [[templates/changelog-deploy]] — Para registrar um deploy importante com mudanças críticas

## Convenção de nomes de arquivo

| Tipo | Pasta | Formato do nome |
|---|---|---|
| Decisão | `decisoes/` | `YYYY-MM-DD-titulo-curto.md` |
| Bug | `bugs-resolvidos/` | `YYYY-MM-DD-descricao-curta.md` |
| Tipo de prompt | `tipos-de-prompt/` | `nome-do-estilo.md` |
| Changelog | `bugs-resolvidos/` ou raiz | `changelog-YYYY-MM-DD.md` |
